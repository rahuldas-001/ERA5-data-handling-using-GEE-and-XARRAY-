# ERA5-data-handling-using-GEE-and-XARRAY-


🌡️ ERA5-Land Temperature Clipping & Visualization with Earth Engine and Xarray
This project demonstrates how to retrieve daily aggregated ERA5-Land temperature data from Google Earth Engine, convert it into an Xarray dataset, and clip it to a user-defined region using rioxarray and geopandas.

📌 Features
Retrieve ERA5-Land temperature data using the Earth Engine Python API

Convert Earth Engine ImageCollection to xarray.Dataset

Visualize temperature maps for daily and weekly periods

Clip temperature data using drawn polygons from an interactive geemap map

Plot the clipped maps with accurate spatial orientation using matplotlib
